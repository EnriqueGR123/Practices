07 / FUNDAMENTOS

Guía académica

¿Qué es una máquina de Turing?

Es un modelo matemático de computación formado por una cinta de memoria, uno o más cabezales, un conjunto de estados y reglas que determinan qué símbolo leer, qué escribir, cómo moverse y a qué estado pasar.

¿Qué representan las cintas y los cabezales?

Las cintas almacenan símbolos del alfabeto. Los cabezales señalan las celdas utilizadas en cada transición. En esta máquina de varias cintas se separan los operandos, la suma, el producto acumulado y el producto parcial. La cinta se expande al acceder a posiciones nuevas.

¿Cómo se suma en binario?

Se recorren los bits desde la derecha. Para cada posición se consideran los bits de ambos operandos y el acarreo anterior. La suma de tres bits se representa mediante un bit de resultado y un nuevo acarreo. Por ejemplo, 1 + 1 = 10 en binario.

¿Cómo se multiplica en binario?

Se procesa cada bit del multiplicador. Un bit 0 produce un producto parcial nulo; un bit 1 copia el multiplicando. Cada producto parcial se desplaza según su posición y se suma al acumulador. La suma utiliza reglas de bits y acarreo.

¿Por qué se eleva al cuadrado multiplicando por sí mismo?

Por definición, x² = x × x. Primero se calcula s = a + b y después se calcula s × s. Por ejemplo: a = 10₂ y b = 11₂; la suma es 101₂ y su cuadrado es 11001₂, que equivale a 25 en decimal.

Estados, aceptación y límites del modelo

Los estados identifican la fase y la operación en curso. HALT es el estado de aceptación: se alcanza únicamente cuando se han procesado todos los bits y se ha terminado la multiplicación. Un límite de pasos evita ejecuciones excesivamente largas.

Este proyecto es una máquina de Turing de varias cintas a nivel de microprograma educativo. Cada transición actualiza símbolos, cabezales y estado, pero algunas rutinas se representan mediante subestados especializados. No pretende ser una tabla mínima universal de una sola cinta.

Ejemplo resuelto

a = 10₂ = 2₁₀
b = 11₂ = 3₁₀
a + b = 101₂ = 5₁₀
(a + b)² = 11001₂ = 25₁₀
